# Historical material

These files preserve previous requirements, architecture sketches, estimates, issue exports and demonstration
reports. Their completion claims, commands and public objects describe their original period. They are not
current usage instructions or acceptance evidence for the migrated model.

- `nkd-v1`, SRD exports and strategy: original product and requirement inputs.
- `nkd-sadd`, architecture and flows: superseded design views.
- Epics, stories, design plans and checklist: earlier planning/audit snapshots.
- Milestone audit and M1 build approach: dated rationale and prior external-run findings.

Use the [current documentation map](../README.md), [milestones](../milestones.md),
[acceptance specification](../epics-v1-spec.md) and [implementation record](../adr/reconciliation.md) for ongoing
work. Original repository-relative paths in historical prose and command blocks are retained as recorded;
these documents are not executable tutorials. Historical presentation exports and editable diagram sources
are preserved outside the repository; current architecture diagrams live in the SADD.
