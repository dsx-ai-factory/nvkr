# nfpm native tool review

The node-image catalog selects nfpm 2.48.0 as an internal Run tool. Its release archives contain exactly
the executables copied from the maintained Packer images for each architecture. This migration changes
the tool binding and provenance, without upgrading nfpm. Ordinary catalog review owns these pins and
the dependency/license inventory below; no image exception is inherited.

## Exact subjects

The [upstream release](https://github.com/goreleaser/nfpm/releases/tag/v2.48.0) identifies source commit
`db22372bfbddb6b2968ff71e9c25e6bb1a2355c2` and Go 1.27.2. Both archives use member `nfpm`.

The compared Packer image manifests are
`sha256:915623e06b2d599ccdaee545d9e657112cd9740603a86e652077564181892f70` (amd64) and
`sha256:2dcb63fc894ec25f8763d37d5139d904be3f6f42c897ca0dd3b32a51f8d36140` (arm64), under

without executing a foreign-architecture binary. The Ubuntu 24 variant retains its separate existing
nfpm 2.47.0 source pin.

## Dependency and license closure

The release provides SPDX 2.3 SBOMs generated by Syft 1.54.0. The accompanying
`nfpm_2.48.0_Linux_x86_64.tar.gz.sbom.json` has SHA-256
`750adda4e23ecee2804739a2df866b49afb99672094205a2c1a0a21bccf63cfe`; the ARM64 SBOM has SHA-256
`3bf772e7db0928841ad42e96700e7cbff717ed190866eab601396a6c8975a7fa`.
Their 76 module entries and Go standard-library entry have identical names, versions and license
expressions across architectures. The archive wrapper adds one entry with no license assertion;
the archive's `LICENSE.md` is nfpm's MIT license. These are upstream inventory descriptions,
not authenticated NVKR execution evidence or a claim of independent source reproduction.

Two upstream `LicenseRef` entries require interpretation of their referenced files:

- `dario.cat/mergo` 1.0.2 points to `testdata/license.json`, a JSON test fixture with no license text.
  Its root `LICENSE` is BSD-3-Clause. The module checksum is
  `h1:85+piFYR1tMbRrLcDwR18y4UKJ3aH1Tbzi24VRW1TK8=`.
- `go.yaml.in/yaml/v4` 4.0.0-rc.6 points to `NOTICE`, which explicitly retains MIT for the eight
  libyaml-derived files and Apache-2.0 for the remaining files. The module checksum is
  `h1:1h7H1ohdUh93/FyE4YaDa1Zh64K6VVbjF4K6WUxMtH4=`. The table records both licenses.

`filepath-securejoin` 0.7.0 includes BSD-3-Clause and MPL-2.0 code; both license files and the
README identify this split. Its source is available at upstream commit
`8096a959c5d7a248976a3531a030f5c4da0a44d0`. Tool acquisition does not redistribute this executable
as a Release member. Any separate redistribution of the tool must retain the applicable notices and
source availability obligations, including MPL-2.0. Generated packages do not inherit a tool's license
merely because that tool created them. This review inventories the existing bytes; it grants no legal
exception or license-policy waiver.
