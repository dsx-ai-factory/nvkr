02 / SELECT

Reuse producers. Be explicit about outputs.

outputs:
- name: cwe
  components: [nke-controller]
  platform: linux/amd64
  format: oci
- name: controller-chart
  components: [nke-controller-chart]
  platform: linux/amd64
  format: helm-oci
  helm:
    images: {controller: cwe}

A real Definition excerpt

Build the controller image. Bind its delivered digest into the chart.

Machine-managed locks pin source commits and acquired bytes. One upstream pin set can select several chart versions.

10 / TRUST

Make the acceptance question explicit.

PLAN

What will run?

Inputs, dependencies, output slots and execution choices.

No execution claim.

BROWSE

What is declared?

Metadata integrity, output membership and evidence subjects.

Payloads, signatures and policy remain unverified.

VERIFY

Do we accept it?

Explicit identity, issuer, lane and evidence scope.

Supported artifact-publication scope needs Linux and pinned cosign.

A pipeline verification record and an independent consumer check are distinct evidence.

Signing & attestationsVerification policyEvidence lanes
