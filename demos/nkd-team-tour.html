NVKE Recipes / Plan and graph

Inspect the work before execution.

The generated Plan connects producer instructions, operations and the artifacts they exchange.

Save canonical Plan JSON, then export its dependency graph.
nkdctl run plan --definition definition.yaml \
  --environment environment.yaml --json > plan.json
nkdctl run graph --plan plan.json --format mermaid

NVKE Recipes / Generated pipelines

Turn the Plan into a GitHub workflow.

The generator creates jobs and transfers. The selected builders produce the artifacts.

Writes a bundle under ./generated. Repeat with --check to detect drift.
mkdir -p generated
nkdctl run generate --definition definition.yaml \
  --environment environment.yaml --engine github --root ./generated

NVKE Recipes / Release structure

One release connects the deliverables.

An immutable release reference leads to named artifacts and their supporting evidence.

RELEASE_REF is the full digest-pinned release reference emitted by publication.
nkdctl release browse --reference "$RELEASE_REF"

NVKE Recipes / Release navigation

Follow one output to its evidence.

The manifest describes the package; the payload is its content. Trace the evidence tied to those exact bytes.

Browsing checks metadata. It does not verify payload bytes, signatures or consumer policy.

OUTPUT_NAME is an exact output name listed by the previous browse command.
nkdctl release browse --reference "$RELEASE_REF" \
  --output "$OUTPUT_NAME" --format mermaid
