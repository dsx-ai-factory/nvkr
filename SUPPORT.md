# Support

## How to get help

| Channel | When to use |
|---|---|
| [GitHub Issues](https://github.com/dsx-ai-factory/nke-recipes/issues) | Reproducible bugs, concrete feature requests, and documentation gaps |
| [GitHub Discussions Q&A](https://github.com/dsx-ai-factory/nke-recipes/discussions/categories/q-a) | Usage questions and answers |
| [GitHub Discussions Ideas](https://github.com/dsx-ai-factory/nke-recipes/discussions/categories/ideas) | Open-ended design proposals and feature ideas needing discussion before an issue |

NKE Recipes is a pre-1.0 proof of concept. Community support is best effort, and fixes target `main`.
See [SECURITY.md](SECURITY.md) for the security-supported version scope.

## Before opening an issue

1. Search existing [issues](https://github.com/dsx-ai-factory/nke-recipes/issues) and
   [discussions](https://github.com/dsx-ai-factory/nke-recipes/discussions) to avoid duplicates.
2. Check the [documentation map](docs/README.md), [development guide](DEVELOPMENT.md), and
   [current implementation record](docs/adr/reconciliation.md).
3. Reproduce the problem from the latest commit on `main` when practical.
4. Include the `nkdctl` version or commit, platform, exact command, coded error, and a minimal reproduction.
   Remove credentials, tokens, private keys, and sensitive infrastructure details.

## Security vulnerabilities

Do **not** open a public issue or discussion for a suspected security vulnerability. Follow the private
reporting process in [SECURITY.md](SECURITY.md).

## Community
